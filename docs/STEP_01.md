# 第 1 步：亲手改变失焦与噪声

本步目标：看懂一次模拟成像，亲自修改两个参数，并用自己的话记录观察。预计用时约 20–40 分钟；不需要先学完光学，也不需要准备照片。

程序使用自行生成的图案。它们包含边缘和细条纹，方便观察细节如何变化。本步只生成模拟观测，尚未进行图像复原或 AI 训练。

## 1. 先理解图像为什么变化

把图案想成许多亮点。每个亮点经过光学系统后都会扩散成一个光斑；这个光斑叫 **点扩散函数（PSF）**。所有光斑叠加，形成模拟图像。

\[
y=h*x+n
\]

- `x`：我们生成的清晰图案，也就是已知真值。
- `h`：PSF，决定每个亮点怎样扩散。
- `*`：卷积，把同一种扩散作用施加到整幅图案上。
- `n`：随机噪声；`y` 是加入噪声后的观测。

本模型先做卷积，再加入噪声。**失焦改变光斑形状；噪声给像素值添加随机扰动。** 两者都会让细节难以辨认，但原因不同。

本步假设灰度、单色，而且整幅图使用同一个 PSF。这样可以把注意力集中在两个参数的作用上。暂时不用研究彩色、画面中心与边缘的差别，也不用把结果对应到某款真实镜头。

**失焦为零仍然会模糊。** 有限圆孔本身会产生衍射，无像差时的光斑也不是一个无限小的点。这里的“原图”是成像前的场景，不是已经通过理想镜头的照片。

## 2. 两个参数代表什么

| 参数 | 含义 | 本步怎么改 |
|---|---|---|
| `--defocus` | 失焦系数 `a`，单位为 waves；在单位 RMS 归一化模式下，表示波前误差相对于波长的大小 | `0`、`0.15`、`0.30` |
| `--noise` | 高斯噪声标准差 `σ`，相对于图像 `[0,1]` 的强度尺度 | `0`、`0.01`、`0.03` |

例如 `σ=0.01` 是标准差为强度范围的 1%，不是每个像素都增加 1%。噪声可以为正或负。`a=0.15` 也不是模糊半径为 0.15 像素，更不能直接换算成某台相机的对焦距离。

## 4. 实验 A：只改变失焦

**运行前先预测：** 失焦从 `0` 增大到 `0.30` 时，细条纹和宽色块，哪个更容易失去结构？把预测写入根目录的 `PARTICIPATION.md`。

保持 `--noise 0.01`，依次运行：

```bash
.venv/bin/python learn_optics.py --defocus 0 --noise 0.01
.venv/bin/python learn_optics.py --defocus 0.15 --noise 0.01
.venv/bin/python learn_optics.py --defocus 0.30 --noise 0.01
```

每次分别观察：PSF 的中心与周围结构怎么变？边缘变得更宽还是出现其他变化？最细的条纹还能分清吗？不要只用“更糊”概括，也不要预设每处细节都会单调变化。

## 5. 实验 B：只改变噪声

**运行前先预测：** 保持失焦不变时，加大噪声会改变 PSF 吗？平坦区域和边缘附近，哪里更容易看出噪声？

保持 `--defocus 0.15`，依次运行：

```bash
.venv/bin/python learn_optics.py --defocus 0.15 --noise 0
.venv/bin/python learn_optics.py --defocus 0.15 --noise 0.01
.venv/bin/python learn_optics.py --defocus 0.15 --noise 0.03
```

中间一组与实验 A 重复，可以直接使用已记录的结果。本步只有五种不同设置。比较时保持其他设置一致，避免同时改两个参数而无法解释变化。
