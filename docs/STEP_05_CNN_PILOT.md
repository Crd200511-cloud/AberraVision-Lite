# 第一次 CNN 试跑：看懂它如何学习

状态：小样本调试已完成，尚未启动正式训练或最终测试。

## 网络做什么

网络读取两个灰度通道：模拟观测 y 与 Wiener 结果 x_W。五层 3×3 卷积依次使用 2→32→32→32→32→1 个通道，前四层后接 ReLU，总共 28,641 个可训练参数。

这些参数在训练中逐渐调整。卷积层利用局部相邻像素的亮度关系提取与组合特征；这里没有预先给每个隐藏通道命名为“边缘”或“噪点”。网络最后输出修正量 fθ，复原图为 x_W+fθ(y,x_W)。

最后一层从零初始化，所以训练前修正量为零，输出恰好等于 Wiener。清晰原图只用于计算误差，不拼入网络输入。输出不经过 Sigmoid，也不在训练前截断；显示和评价才按统一规则截到 [0,1]。

## 本次试跑安排

| 设置 | 数值 |
|---|---|
| 数据 | 冻结清单中前 8 张训练图、前 4 张验证图 |
| 训练轮数 | 12；另记录训练前第 0 轮 |
| 每轮 | 每张训练图随机取 4 个位置，共 32 个裁块 |
| 每批 | 4 个裁块，每轮更新 8 次 |
| 有效训练块 | 128×128，额外读取四周各 5 像素作上下文 |
| 优化器 | Adam，学习率 0.0005，无学习率调度、无权重衰减 |
| 训练损失 | 未截断输出与原图的平均绝对误差 L1 |
| 种子 | 20261012，用于参数初始化与裁块顺序 |
| 固定 Wiener | K=0.01，与传统基线一致 |
| 设备 | CPU，4 线程，PyTorch 2.14.1 |

每张原图先在完整 384×384 场景上生成观测和 Wiener 结果，再裁训练块。5 像素上下文对应本网络的感受野半径，避免计算训练损失时用到裁块边缘的人为填充。已用非零修正网络检查，裁块中心输出与整图相应区域一致。

本次每张照片只生成一个固定噪声阵列，种子仍为 100000+原图整数 ID。没有使用测试图，也没有把预实验模型当作正式训练起点；正式训练将重新初始化。

## 如何看曲线

图像见 `results/cnn_pilot/run_01/learning_curve.png`。

- 蓝线：8 张训练原图上的监测误差。
- 橙线：4 张验证原图上的监测误差。
- 橙色虚线：这 4 张验证图的 Wiener 基线误差。
- 黑圈：按验证误差最低的规则保留的试跑模型。

两条实线都在每轮结束后，对完整图像推理，再对中央 256×256 统一截断计分并按原图平均。训练实际优化的是随机块上的未截断 L1，单独保存为 CSV 的 `patch_optimization_l1`，没有把这两个不同口径的数值混画成训练与验证曲线。

蓝线高于橙线不自动表示程序有错：它们来自不同照片，难度可能不同。应首先关注各自随训练的变化、验证相对基线的变化，以及逐图记录。

## 实际结果

| 指标 | 结果 |
|---|---:|
| 训练监测 L1，第 0 轮 | 0.048727 |
| 训练监测 L1，第 12 轮 | 0.046317 |
| 验证 L1，第 0 轮（Wiener） | 0.040614 |
| 验证最低 L1，第 11 轮 | 0.039146 |
| 验证 L1，第 12 轮 | 0.039257 |
| 训练及监测总耗时 | 约 17.22 秒 |
| 稳定阶段每轮更新耗时中位数 | 约 0.64 秒 |
| 每轮整图监测耗时中位数 | 约 0.72 秒 |
| 保存／加载后预测最大差异 | 0 |

第 11 到 12 轮，训练误差仍下降，但验证误差小幅上升。因此不能仅按“最后一轮”或“训练误差最低”保留模型。本次规则在运行前确定：按最低验证监测 L1 选模型，包含第 0 轮，相等时保留较早轮次。

单次小幅回升不足以证明过拟合；随机裁块与优化波动也可能引起曲线起伏。过拟合需要结合更持续的趋势与独立评价判断。这 4 张验证照片参与了模型选择，因此不能作为最终测试成绩，也不足以证明模型普遍有效。
