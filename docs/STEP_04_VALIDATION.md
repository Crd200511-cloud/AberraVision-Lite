# 从两张示例到验证集选参

用户对增大 K 的总结是：“减少噪点，但也会让画面变模糊”。接下来将这种权衡转化为可重复的参数选择。

## 在运行前确定规则

- 来源划分固定为 100 张训练、20 张验证、30 张测试；按原图划分，检查重复后冻结。
- 候选 K 固定为 0.0001、0.001、0.003、0.01、0.03，不根据结果继续追加候选。
- 使用 20 张验证原图；每张图在所有候选 K 下共享同一观测与 PSF。
- 场景 384×384，固定失焦 0.15 waves、噪声 σ=0.01；其他采样参数沿用已验证的模型。
- 先在两张教学训练照片上检查加密光瞳和扩展 PSF 的成像差异，通过既有容差后才开始验证选参。
- 验证计分取中央 256×256，先将预测截到 [0,1]，计算各原图 L1，再对 20 张图取平均。中央区域在运行前确定，不按结果调整。
- 选择平均 L1 最低的候选；若出现完全相等的最小值，选升序列表中的第一个。

教学局部比较曾使用中央 128×128；下表使用中央 256×256，而且图像也不同，不能与两张教学图的数值直接比较。未来正式测试仍按计划报告 PSNR/SSIM；此处 L1 用于选参。

## 实际结果

| K | 验证集平均 L1（越低越好） |
|---:|---:|
| 0.0001 | 0.070930 |
| 0.001 | 0.047768 |
| 0.003 | 0.040847 |
| **0.01** | **0.038818** |
| 0.03 | 0.043207 |

按预定规则，选择 **K=0.01**，后续传统基线和 CNN 的 Wiener 前处理共用这一参数。它是在这些候选、该验证集与当前固定成像条件下的选择，不是对任意图片或噪声都最优。

增大 K 后误差先降低又升高，说明不宜一味加大正则化。这与降噪和细节保留的权衡相符；仅凭这条曲线不能把所有误差变化都归因于某一种机制。

## 接下来你参与什么

我们将建立一个小型 CNN：读取观测 y 与已选参数的 Wiener 结果 x_W，预测修正量。先做小样本调试并测量运行耗时，再冻结训练预算并正式训练。你将参与阅读训练与验证误差曲线，判断网络是否在学习，以及何时出现过拟合迹象。
